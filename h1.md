# Debian 13 VM

Käytän tätä kurssia tehdessä Linuxin konetta (Fedora 44), jossa minulla on käytössä Virt-manager minkä kautta pyöritän debian 13.
Lataamani tiedosto : debian-13.7.0-amd64-netinst.iso

Asetukset:

Kieli: English

Location: Afica, Egypt

Default locale: United States en_US.UTF-8

Näppäimistö: Finnish

Disk partititon: use entire disk, one partition.

Debian mirror: Finland / deb.debian.org

Debianin käynnistyksen jälkeen tein päivitykset alkuun, missä myös huomasin että käyttäjälläni ei ollut root oikeuksia.
alkuun hyppäsin rootiksi "su -" komennolla minkä jälkeen tein päivitykset "apt-get update" ja varmuuden vuoksi laitoin myös "apt-get -y dist-upgrade"
tämän jälkeen kävin laittamassa palomuurin päälle "apt-get install -y ufw" --> "ufw enable".
ja sitten myös lisäsin vielä käyttäjälle rootti oikeudet "usermod -aG sudo sj" ja tein rebootin minkä jälkeen sudo toimi.

## SSH asennus

Näppäilin komento riville "sudo apt-get -y install ssh" ja sitten vielä että pysyy päällä buutin jälkeen "sudo systemctl enable --now ssh"
testi "ssh localhost" --> toimii ja firefoxin "http://localhost" ja debianin sivu sieltä aukeaa.

tämän jälkeen tein avainparit ja kopioin pub avaimen ja "ssh localhost" ei promptaa enää salansaa.
