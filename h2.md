## Sudo without password Manuaali harjottelu.
Aluksi tein uuden käyttäjän debian VM:lle nimeltä "antero" - > "$ sudo adduser antero"

Tämän jälkeen tein uuden ryhmän mihin sitten myöhemmin antero lisätään. "$ sudo addgroup sudoless"

Ja antero vielä ryhmään "$ sudo adduser antero sudoless"

Testi onko antero ryhmässä "$ id antero" = ok

Kun olin lisännyt anteron ryhmään sudoless, haluttiin, että ryhmällä "sudoless" on pääsy root komentoihin ilman, että joka sudo komennon jälkeen tarvitsee naputtaa salasanaa.

Ensiksi avasin uuden shelli ikkunan mihin kirjauduttiin sudo oikeuksilla "sudo -i" jos jokin menee pieleen niin on tarvittaessa backup plan.

visudo teksieditorilla muokkasin /etc/sudoers.d/sudoless tiedostoa, johon laitettiin uusi sääntö.

"%sudoless ALL = (ALL) NOPASSWD: ALL 

% Määrittää ryhmän -> (1st ALL) Määrittää Host/koneet --> (2nd ALL) Käyttäjät --> NOPASSWD: ALL (kaikille komennoille).


Tämän jälkeen vielä kokeilu, päästäänkö käyttämään antero käyttäjällä sudo oikeuksia ilman salasanaa.

Remote yhteys ssh:lla anteron käyttäjään "$ ssh antero@localhost"

sudo komento echolla ja shelli ei promptaa salasanaa --> testi ok.

ansible.cfg tehdään static inventory mikä määrittelee mihin hosteihin Ansible kohdistetaan.

Tässä tapauksessa en tehnyt erillistä inventory fileä vaan ansible.cfg tiedostossa on määritelty, että ansible hakee inventoryn host.ini tiedostosta.

Host.ini määritellään mitä servereitä Ansiblen määritykset koskevat eli tämä toimii niin ikään inventory tiedostona.

site.yml toimii playbookkina mikä suorittaa roolien tehtävät ja lukee inventorystä mitä hosteja ne koskee.


## Ansible käyttäjä ansam

roles/ansam/tasks/main.yml  (Tämän roolin tarkoitus on tehdä ansam käyttäjä)

  
```yaml

- name: Create a group sudoless
  ansible.builtin.group:
    name: sudoless
    state: present


- name: Create user 
  ansible.builtin.user:
      name: ansam
      state: present
      groups: sudoless
      append: true


- name: SSH KEY
  ansible.posix.authorized_key:
      user: ansam
      state: present
      key: ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIAWAyfRqUDvoZqeRl97G7AAjEei+AOdLg1t9FophNaA0

- name: passwordless sudo
  ansible.builtin.copy:
      dest: /etc/sudoers.d/sudoless
      content: "%sudoless ALL =(ALL:ALL) NOPASSWD: ALL\n"
      owner: root
      group: root
      mode: "0644"

```

## Packages rooli (apache ja curl)

```yaml

- name: install apache and curl
  ansible.builtin.apt:
    name:
      - apache2
      - curl
    state: present

- name: start apache2
  ansible.builtin.service:
    name: apache2
    state: started
    enabled: true
```


## Firewall (ufw)

```yaml

- name: install ufw
  ansible.builtin.apt:
    name: ufw
    state: present

- name: allow port 22
  community.general.ufw:
    rule: allow
    port: "22"
    proto: tcp

- name: Allow http port 80
  community.general.ufw:
    rule: allow
    port: "80"
    proto: tcp

- name: Limit connection rate on port 22
  community.general.ufw:
    rule: limit
    port: ssh
    proto: tcp

- name: Default incoming policy
  community.general.ufw:
    direction: incoming
    policy: deny

- name: Default outgoing policy
  community.general.ufw:
    direction: outgoing
    policy: allow

- name: Enable UFW
  community.general.ufw:
    state: enabled
    
```

## Playbook (site.yml)


```yaml

- name: configure upcloud
  hosts: testserver   #upcloud palvelin nimi 
  become: true #antaa korotetut oikeudet
  roles:   #ajaa roolin ansam
    - ansam
  tags: upcloud  #helpottaa testaamista

- name: Configure upcloud packages and ufw
  hosts: testserver
  become: true
  roles:
    - packages
    - firewall
  tags: packages

```
